# 📄 AI Document & Chat Assistant

An AI-powered document assistant built with **Streamlit** and **Google Gemini AI**. This application allows users to upload documents, ask questions, summarize content, and interact with documents through an intelligent chat interface.

## 🚀 Features

* 📂 Upload PDF and DOCX files
* 🤖 Chat with your documents using Google Gemini AI
* 📝 Generate document summaries
* 💬 Interactive AI chatbot
* 🎨 Modern and responsive Streamlit interface
* 🔐 Secure API key management using `.env`
* ⚡ Fast and easy to use

## 🛠️ Tech Stack

* Python 3.12+
* Streamlit
* Google Gemini API
* python-dotenv
* PyPDF
* python-docx
* Pillow

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/AI-document.git
cd AI-document
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**Mac/Linux**

```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 Configure Google Gemini API

Create a `.env` file in the project folder.

```env
GOOGLE_API_KEY=YOUR_GEMINI_API_KEY
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

The application will open automatically in your browser.
